## Miniature Paint Color Picker

Cross-platform desktop app (Avalonia UI, C#).
A tool for choosing and mixing paints for miniature painting.

### Planned features
- Paint mixing simulation
- Most common paints database
- Eyedropper for picking colors from pictures
- Canvas for testing picked paints

### Status
Early phase - project setup, learning Avalonia/MVVM

### Stack
- C# / .NET
- Avalonia UI
- SQLite
- SkiaSharp (probably)

### Plan
- [ ] Stage 1: Desktop app
- [ ] Stage 2: Web port (TypeScript, React)

### Running locally (for now)

dotnet run --project MiniPaintingApp
